# FLASH EXCHANGE

Стартовая структура Telegram-магазина на Python + SQLite.

## Структура
- `config.py` — настройки магазина
- `.env.example` — секреты/переменные окружения
- `database.py` — SQLite
- `bot.py` — точка входа
- `handlers/` — обработчики
- `payments/` — платежные интеграции
- `assets/` — картинки
- `data/` — база данных

Секреты в `.env` не коммитьте в GitHub.
